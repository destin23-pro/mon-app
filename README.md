# Projet de démo : Next.js + Spring Boot

- backend/  : API Spring Boot (GET /api/hello)
- frontend/ : site Next.js qui appelle l'API

## Tester en local
Backend :  cd backend && mvn spring-boot:run     (http://localhost:8080/api/hello)
Frontend : cd frontend && npm install && npm run dev   (http://localhost:3000)
